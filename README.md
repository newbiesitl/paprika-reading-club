## Working principle

Keep four kinds of information distinct: what a source claims, what its evidence establishes, what the human explicitly thinks, and what an agent proposes. Reading history is evidence of engagement, not automatic endorsement. Personal methodology remains a set of revisable proposals until the Research Director confirms it.

This repository stores source links, original notes, and curated summaries. Private conversation evidence, actual service/chat bindings, and unpublished personal reflections stay outside public Git. Paper PDFs are linked rather than copied by default.

The initial company definition is a bootstrap candidate. File validation, native chat onboarding, scientific review, and publication are separate states; see the local initialization report for the current status.
