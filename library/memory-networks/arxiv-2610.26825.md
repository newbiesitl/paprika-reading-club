## Current orientation

MemT-1 combines dynamic local memory with trained memory-processing parameters. During online interaction the dynamic state changes while learned parameters stay fixed. Its stated lineage is Metis and a stabilized Gated DeltaNet-2 update. Fixed-capacity retention remains a tradeoff; memory-state adaptation is not equivalent to unconstrained continual retraining.
