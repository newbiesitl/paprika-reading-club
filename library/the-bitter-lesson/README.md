# The Bitter Lesson

A human-selected reading category anchored by [Richard Sutton's essay](sutton2019bitter.md): investigate how learning and search can improve as resources grow, and which human-designed assumptions may restrict that progress. The club's proposed evaluation checklist remains in the [methodology card](../../methodology/the-bitter-lesson.md).

## Reading map

| Reading | Place in the category | Main question |
| --- | --- | --- |
| [The Bitter Lesson — Richard Sutton (2019)](sutton2019bitter.md) | Foundational essay | Which approaches keep improving with computation, data, and experience? |
| [AlphaGo — Mastering the game of Go with deep neural networks and tree search (2016)](silver2016alphago.md) | Supervised bootstrapping, self-play, and search | What does each learning stage contribute? |
| [AlphaZero — Mastering Chess and Shogi by Self-Play with a General Reinforcement Learning Algorithm (2017)](arxiv-1712.01815.md) | Learning without human demonstrations | Which assumptions remain after expert trajectories are removed? |
| [From Tokens to Bytes I: Scaling Hierarchical Networks (2026)](cartesia2026tokensbytes.md) | Learned representations and segmentation | What changes when token boundaries can be learned? |
| [HNet — Dynamic Chunking for End-to-End Hierarchical Sequence Modeling (2025)](arxiv-2507.07955.md) | Supporting architecture paper for Tokens to Bytes | How is chunking learned, and which comparisons isolate its benefit? |

## How to read the connections

Start with Sutton, then compare AlphaGo and AlphaZero. Read the Tokens to Bytes article alongside its HNet architecture reference as a separate thread about representations. These are related through the club's research questions, but they use different mechanisms: the HNet example is not an RL result.

This grouping reflects the Research Director's requested category. It does not establish that every paper proves the essay's thesis, that all human priors are harmful, or that learning finds a global optimum. Keep source evidence and the club's interpretation separate; independent scientific review is still pending.
